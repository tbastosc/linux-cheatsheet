Processo de Arranque do Linux
  • 1. BIOS/UEFI — POST, identifica hardware, carrega o gestor de arranque do MBR/EFI
  • 2. GRUB2 — carrega o kernel (/boot/vmlinuz-*) e o initrd
  • 3. initramfs — sistema em RAM; monta a raiz definitiva
  • 4. Kernel — inicializa hardware, monta a raiz, inicia init
  • 5. systemd (PID 1) — gere targets, unidades, dependências
  • 6. Targets — sysinit → basic → multi-user → graphical
  • 7. Login — Getty, PAM, shell do utilizador

Inodes, Ligações & Sistema de Ficheiros
